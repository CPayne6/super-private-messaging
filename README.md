# VaultChat

VaultChat is a privacy-focused messaging application with an encrypted vault
stored locally on the user's device.

## Development

```bash
pnpm install
pnpm dev
```

The web application is available at `http://localhost:3010` and the API at
`http://localhost:8010`.

See `docs/LOCAL_DEVELOPMENT.md` for local setup and `docs/PRODUCTION.md` for
deployment.
